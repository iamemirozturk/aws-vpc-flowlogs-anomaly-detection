# Code of conduct

Contributors are expected to be respectful, constructive, and security-minded.
Harassment, discriminatory language, deliberate exposure of sensitive data,
and disruptive behavior are not acceptable.

Report conduct concerns privately to the repository maintainer. The maintainer
may edit or remove contributions, comments, issues, or participation that
violate these expectations. Enforcement decisions should be proportionate,
documented, and focused on maintaining a safe technical community.

This policy applies in repository spaces and when representing the project in
public community spaces.
